Design Principles

    Mobile-First Responsive

    Action-Oriented
    Clear CTAs guide users toward joining the community

Page Wireframes

Structural layout wireframes showing content hierarchy and spatial relationships.

Home Page — Hero + Navigation

★ Fixed navbar (72px height) with frosted glass effect. Hero uses 2-column grid with SVG illustrations.

Home Page — Value Propositions

★ 4-column grid with icon cards. Each card has hover lift effect. Collapses to 2-col on tablet, 1-col on mobile.

Home Page — Trending Discussions

★ 2-column intro (text + illustration) followed by 3-column discussion cards with category badges, author avatars, and engagement metrics.

Footer

★ Dark footer with 4-column grid: Brand info (2fr) + 3 link columns (1fr each). Social icons row at bottom.

Join Page — Registration

★ 2-column layout: Benefits list with icons on left, registration form with shadow card on right. Form includes social login options.
